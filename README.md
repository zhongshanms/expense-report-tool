# 费用报销 Excel 自动生成工具

拖拽发票文件夹，自动识别费用明细，一键生成标准格式的 Excel 报销表。

## 功能

- 📖 **工具使用说明**：首次打开显示完整使用指引
- 📂 **文件夹导入**：拖拽或选择发票文件夹，自动识别 PDF 金额与费用类别
- ✏️ **编辑确认**：表格直接修改、增删行，灵活调整
- 📥 **下载 Excel**：生成样式规范的 Excel 文件（微软雅黑、细线边框、合计行）
- 🤖 **智能分类**：自动识别通行费/加油费 → 汽车费用，默认部门「产品质量」
- 🔒 **隐私保护**：无登录、无 localStorage/sessionStorage，数据不持久化

## 使用方式

直接在浏览器打开 `index.html`（推荐 Chrome / Edge），或访问 GitHub Pages：
https://zhongshanms.github.io/expense-report-tool/
